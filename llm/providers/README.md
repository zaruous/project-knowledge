# LLM Provider Guidance

The repository keeps project knowledge vendor-neutral. Provider-specific behavior belongs under this directory and must not redefine core governance rules from `AGENTS.md`.

- `common/`: rules shared by all LLM providers.
- `claude/`: Claude/Claude Code usage notes.
- `openai/`: ChatGPT/Codex usage notes.

Authoritative project knowledge remains in `wiki/`, `entities/`, and governed data paths regardless of model provider.
