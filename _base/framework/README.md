# Project Knowledge Base Framework

이 디렉터리는 특정 도메인에 종속되지 않는 프로젝트 관리 원칙을 정의한다.
집 구하기, YMS 품질분석 등 실전 POC의 데이터나 업무 용어는 이 영역에 직접 반영하지 않는다.
실전 프로젝트에서 검증된 패턴만 `governance/adoption/` 절차를 거쳐 공통 프레임워크로 채용한다.

핵심 흐름:

`Objective -> Subject/Candidate -> Evidence -> Metric/Criterion -> Evaluation -> Decision -> Action -> Validation`

데이터 흐름:

`incoming -> raw -> staging -> normalized -> derived -> snapshot/evidence -> evaluation`
