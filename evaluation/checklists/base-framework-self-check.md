# Base Framework Self Check

- [ ] 특정 도메인 데이터가 공통 프레임워크에 직접 포함되지 않았다.
- [ ] Objective가 정의되어 있다.
- [ ] Subject/Candidate와 Evaluation의 관계가 추적 가능하다.
- [ ] 중요한 Evaluation은 Evidence와 연결된다.
- [ ] 평가 점수와 Confidence를 구분할 수 있다.
- [ ] 시점 변화가 필요한 데이터는 Snapshot으로 관리할 수 있다.
- [ ] Raw 데이터는 불변 원본으로 관리된다.
- [ ] Raw에서 Derived까지 Lineage를 기록할 수 있다.
- [ ] Criterion/Metric/Weight가 데이터와 분리되어 있다.
- [ ] Quality Gate가 정의 가능하다.
- [ ] Decision이 사용한 Evaluation을 추적할 수 있다.
- [ ] Action 이후 Validation 결과를 연결할 수 있다.
- [ ] POC 아이디어의 Adoption/Reject 근거를 기록할 수 있다.
- [ ] 자동 검증 스크립트가 실행된다.
- [ ] ChatGPT/Codex/Claude가 동일 공통 규칙을 읽을 수 있다.
